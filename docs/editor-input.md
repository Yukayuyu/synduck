# 0.3.1 输入修复

0.3.1 修复画布内连续输入丢字和编辑按键被画布接收的问题。旧实现每次输入都会把包含输入框的内容重新同步到整组 React Flow 节点；延迟同步和持续的节点更新会干扰输入。现在卡片文字通过 React Context 直接更新，打字时保留原有节点与输入框。

文字区域内的按键交给浏览器处理，包含中英文逗号、标点、中文输入法候选键、Shift 选取、Ctrl/Cmd 快捷键与换行。松开按键的事件仍会释放画布的组合键状态，避免在进入输入框前按下 Shift 后卡住画布选取。Tab 和点击其他区域可以正常离开输入框。

## 更新本地 Windows 安装

已使用 0.2.0 或 0.3.0 管理式启动器：

1. 先保存需要保留的未发送文字，完成回答和本地任务；清空草稿后才能安装更新。
2. 打开「版本與更新」，导入完整 `ContextCanvas-Windows-0.3.1.zip`，点击「安裝新版並重新啟動」。无需解压更新 ZIP。
3. 重启后刷新浏览器页面，确认「版本與更新」显示 **0.3.1**。

画布、登录和已保存的模型设置沿用原安装。此前未使用管理式启动器的旧包，按[首次升级说明](local-runtime-updates.md#windows-使用與首次升級)转换；新安装则完整解压 ZIP 后运行 `Start-ContextCanvas.cmd`。

源码安装需重新安装锁定依赖、构建前端，再重新启动本地启动器。仅刷新页面不会更新未重新构建的前端。

此包用于本地导入测试。GitHub Releases 尚未发布 0.3.1，线上检查更新不会发现这个本地文件。

## 验证范围

Chromium 回归覆盖实际逐键快速输入、标点、选区替换、撤销/重做、Tab 导航、草稿送出与清空、五分钟模拟时间、画布缩放和后台更新通知。输入法候选确认使用组合输入事件模拟；云端 Linux 无法验证 Windows 实际中文输入法的候选窗口和 iOS 原生键盘。

本修复没有更改数据库 schema 或上下文来源记录。
