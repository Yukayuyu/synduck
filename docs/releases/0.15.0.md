# Context Canvas 0.15.0

- 长对话超出上下文预算时，优先保留最新的消息原文（以前先保留最早的）。当前对话和分支继承的上层对话都适用。
- 新增「背景摘要」：在检查器的提示或对话卡片菜单中生成。放不下的较早消息由摘要代替，最新消息仍用原文；预算充足时始终使用原文。
- 检查器标明摘要代替了哪些消息，可随时停用或重新生成。
- 分支不会使用覆盖了其建立之后内容的摘要；被排除、删除或已变化的来源会使摘要失效；明确选中或固定的对话仍须完整发送。
- 实验性：Mac 后端可撷取并操作选定的应用程序窗口，需要授予「螢幕與系統錄音」与「輔助使用」权限；已在 CI 的 macOS 环境对真实窗口验证，尚未经实体 Mac 人工验证，见[macOS 桌面控制](../macos-desktop.md)。

摘要由当前模型生成并消耗额度；演示模式只保存带标注的占位内容。无 SQL／画布迁移，旧回答的输入包保持原样；含摘要的项目文件需 0.15.0 或更新版本导入。详见[背景摘要说明](../summaries.md)。
