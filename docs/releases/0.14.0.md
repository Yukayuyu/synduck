# Context Canvas 0.14.0

- 新增「脉络链」：模型现在知道每段背景来自哪条对话，以及它与当前对话的关系（上层分支、顺手问、摘录、汇合，或参考来源）。来源按「先背景、后当前对话」的顺序送入，模型被指示沿链推理，并在多条对话观点不同时分别比较与归属。
- 上下文检查器显示脉络链，可点击回到对应卡片；每条来源标明所属对话。历史回答保存当时的链。
- 只引用片段的对话、从摘录开始的对话和含已排除内容的对话，名称不会发送给模型；被排除的来源不出现在链中。
- 进入输入的内容和预算取舍规则不变。

无 SQL／画布迁移。旧回答的输入包保持原样；含脉络链的项目文件需 0.14.0 或更新版本导入。详见[脉络链说明](../context-chain.md)。
