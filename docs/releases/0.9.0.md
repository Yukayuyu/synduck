# Context Canvas 0.9.0

- 普通画布对话接入本地执行器：启用项目并选择已登录的 ChatGPT / Codex 模型后，模型自行决定何时读取文件、修改代码或调用命令、MCP 与桌面工具。输入框不再有「交给本地任务」。
- 操作进度、具体确认、截图与可导出记录显示在原回答中，重启后仍可追溯到同一个回答和输入包。
- 纯文字对话保持并行；共享执行器一次执行一段工具对话。停止回答会撤销待确认操作，失败后的直接重试不会重放有副作用的操作。
- 保留逐次写入、命令和外部工具确认，以及原有的项目设置、手动测试和旧任务记录。

现有启用的项目会自动使用新入口；首次使用需指定后端目录并完成 ChatGPT 登录。Demo／直接 API 模式不执行工具。每轮最多 20 次操作、15 分钟，原有文件、输出和图片限制仍适用；本版并非接入原生 Codex 的全部工具。详见安装包 `docs/developer-workflow.md`。

无 SQL migration；任务记录新增可选 `conversation_turn_id` 关联，不改写旧画布文本或历史上下文。完整备份需保留 data/，单张画布 JSON 不包含操作日志与截图。安装与匿名更新不需要 GitHub token；在「版本与更新」检查、安装并重启即可。
