# Context Canvas 0.11.0

- 首次项目配置可在普通画布完成：直接提供后端电脑的目录与需求，AI 在卡片请求授权，确认后验证／启用目录，并在同一轮继续执行，不再先要求去设置填写路径。
- 可选择保留写入／命令逐次确认，或「授權並自動執行本次任務」。自动权限仅限当前任务，结束、停止、失败和重启后收回；MCP 与桌面仍逐次批准。
- 命令输出实时显示，支持非秘密的初始标准输入，方便 GitHub 官方浏览器／设备授权。ChatGPT 登录、目录授权与 GitHub 登录各自独立；GitHub 本人认证仍需在官方页面完成。
- 顶部显示项目待授权／已连接状态；记录保留实际后端系统、目录、参数、结果和每个自动操作对应的授权。Windows 短路径与目录别名会统一解析，避免路径比较及应用数据目录保护失效。

没有 SQL 或画布迁移，已有参考、来源与历史输入包保留。项目目录是命令的工作目录，命令仍以后端系统用户权限执行，并非系统沙盒。需使用已登录的 ChatGPT / Codex 模型；后端显式禁用执行器时需由拥有者启用并重启。安装与匿名更新不需要 GitHub token。
