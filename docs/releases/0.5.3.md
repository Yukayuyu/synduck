# Context Canvas 0.5.3

首个采用单仓库发布流程的正式版本：源码、问题反馈、Windows 安装包与更新清单统一在 `Yukayuyu/synduck`。项目采用 MIT 许可证。

- 下载与检查更新无需 GitHub 账号或 token，发布使用 GitHub Actions 内置凭证。
- 在大画布上阅读相邻的输入／输出块、摘取文字并延伸分支，检查每次回答使用的上下文。
- 支持官方 ChatGPT / Codex 设备码登录、有效模型清单和思考深度选择，也可配置直接 OpenAI API。
- 本地项目工具、MCP 和 Windows 窗口操作提供逐次确认、截图证据与任务回看。
- Windows 编译包包含 MIT 许可证及完整中文安装、模型、iOS、备份和升级指南。

首次使用：下载 `ContextCanvas-Windows-0.5.3.zip`，完整解压，运行 `Start-ContextCanvas.cmd`。首次启动会联网准备 Node.js 24 和固定运行依赖。可以先体验 Demo，再在「模型與登入」连接自己的账号。

从 0.5.2 及更早测试版升级：取得完整 ZIP，在原安装「版本與更新」匯入并安装，然后关闭整个启动器，再从原安装目录启动。画布、模型设置、登录和本地任务会保留。旧客户端内的更新来源不会因 GitHub 设置改变而自动切换，因此首次迁移需要手动取得新版包。

后续在后端运行时每 15 分钟检查新版，下载后由用户选择安装时间。iPhone／iPad 需通过可信 HTTPS 连接持续运行的后端；实体桌面操作和模型使用权限仍由本机环境与账号决定。
