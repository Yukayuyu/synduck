# Context Canvas 0.10.0

- 新增「參考」入口：貼上文字，或匯入 UTF-8 TXT、Markdown、PDF 與 Word DOCX，建立獨立文件參考卡片。
- 參考可加入本輪上下文、固定、排除，或「以此提問」；不會在匯入時自動傳給 AI。全文超過上下文預算會明確阻擋，亦可 Pick 片段提問、匯合及跨畫布引用。
- 長文件提供分頁與全文文字尋找；摘錄和回到來源保持完整原文座標與雜湊，支援回收桶、重啟和備份保存。
- PDF／Word 在受時間和 heap 限制的獨立 worker 解析。單檔上限 5 MiB、文字上限 1 MiB，掃描文件請先 OCR；保存擷取文字與來源資訊，不保存原始 PDF／DOCX 二進位檔或版面。

無 SQL migration。操作與限制見安裝包 `docs/references.md`。安裝及匿名更新不需要 GitHub token；在「版本與更新」安裝並重新啟動即可。
