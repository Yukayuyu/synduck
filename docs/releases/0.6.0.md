# Context Canvas 0.6.0

- 对话按独立话题区域显示，输入／输出紧密成组，左侧顺序线保持阅读方向；可折叠整条对话。Pick 使用从原文位置出发的弧线。
- 输入框左下角「＋」添加「分支 /fork」或「顺手问 /btw」。也可在主输入末尾输入命令后按 Enter。每批最多八个分支，分别回答、停止、重试和继续追问；主线生成中也可发送分支。主线上保留分支索引和待答数量。
- 摘录卡点「收集」，到任意对话选中文字并「加入汇合点」。每个汇合点最多 200 处摘录，逐条回到来源或移出；通过「延伸提问」继续。来源改变只影响下一轮，历史回答和输入包不改写。
- 分叉背景固定到创建时的原文 ID，不混入后续主线或兄弟分支。未开始的分支初始问题保存在本地，刷新后可找回。
- 保留原文、UTF-16 选区、快照、哈希和每轮上下文。无需 SQL migration，旧项目可直接打开；含新字段的备份需 0.6.0 或更新版本导入。

`/fork` 和 `/btw` 目前都建立可持续对话，区别在名称与任务标记；顺手问不会自动把回答写回主线。共用约束应先保存在主线，或明确写入各问题。同批的新主线问题不会自动成为兄弟任务的共享指示。选中／固定的汇合点，以及汇合分支的来源，超出预算时阻止发送并展示问题，不会静默丢掉部分摘录。

在「版本与更新」检查更新，完成任务并保存草稿后安装、重启。普通用户不需要 GitHub token。
