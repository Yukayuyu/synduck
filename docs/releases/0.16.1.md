# Context Canvas 0.16.1

- 修正：在 ChatGPT／Codex 模式下，每次提問都出現「Codex 拒絕回答的 JSON 格式規格」而無法回答。0.16.0 新增的腦力激盪讓回答格式多了一種提案，產生的格式規格用了 Codex 嚴格模式不接受的寫法。現在所有模式共用同一份回答格式，並只使用各家嚴格模式都接受的寫法；新增的測試會在格式超出這個範圍時失敗。Claude 模式不受影響。
