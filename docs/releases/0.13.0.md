# Context Canvas 0.13.0

- 新增「连接账号与服务」入口。GitHub 在官方页面登录一次，后续画布和项目共用；无需手动设置 MCP、安装登录工具或填写 token。
- 普通 ChatGPT / Codex 对话可直接提出「连接 GitHub」等需求，在原卡片点按钮授权，完成后继续同一轮任务。登录与本机目录／操作授权分开管理。
- 支持在线 MCP 服务的标准网页登录、刷新和重启复用，提供 Notion、Linear、Figma 及网页浏览预设。其他在线服务只填名称和地址；服务是否允许登录仍由其授权政策决定。
- 手动工具输入改为普通表单，操作确认优先显示自然语言说明；自定义本机连接收进折叠的高级设置，启动选项一行一项填写。原始追溯保留，命令输出按需展开。
- 连接状态刷新不重建输入框；跨画布、重启复用、取消与回调校验均有回归测试。

GitHub 授权页面显示所用的官方组件名称 GitHub CLI。凭据仅保存于后端本机受限文件，不是加密保险箱；完整数据备份包含登录，请私下保存。「仅从 Synduck 断开」不会撤销服务方授权。组织权限、SSO、服务方案仍适用；Git 操作需要电脑已安装 Git，网页浏览需要 Chrome。

Windows 与 macOS 使用各自的 ZIP 和更新清单，画布、模型登录及旧设置保留，无 SQL／画布迁移。安装和匿名更新不需要 GitHub token。
