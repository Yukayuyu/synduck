# Context Canvas 0.5.4

不同对话现在可以同时生成回答。送出一个问题后，切到另一张卡片即可继续提问，不再锁住整张画布。

- 每段回答单独显示生成内容、停止按钮和错误；停止／失败不会中断其他对话，可使用原上下文重试。
- 一段回答完成时，保留其他卡片正在输入的文字、游标、选区和上下文预览。
- 其他卡片的阅读、建立分支、命名和删除可继续进行；同一段对话仍依序提问。
- 直接传送会原子整理和封存上下文，避免同时提交不同问题时互相触发过期校验；显式预览仍保留版本检查和来源保护。
- 模型／账号切换、项目整体恢复和更新安装继续等待所有回答结束。

无需增加 API key、开关或数据库迁移，ChatGPT / Codex、直接 OpenAI API 与 Demo 均支持。并行共用当前模型、思考深度与账号额度，仍受模型服务的速率限制。

现有 Windows 安装取得完整 `ContextCanvas-Windows-0.5.4.zip` 后，可在「版本與更新」匯入、安装并重启启动器。画布、登录与模型设置会保留。iOS 用户更新提供服务的电脑后刷新页面即可。
