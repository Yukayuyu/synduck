# Context Canvas 0.7.0

- 左上角画布名称可打开列表：新建、切换、查找与重命名。原有数据自动成为第一张画布。
- 每张画布独立保存对话、节点、固定／排除、位置、视角和浏览器草稿。刷新后记住上次选择；正常完成的问题不会重新变成草稿，停止或生成失败时保留问题供修改重发。
- 生成时可以切去另一张画布继续输入。后台回答继续完成，停止与重试只作用于所属画布；其他画布完成回答不会移动当前输入光标。
- 选中文字后可「引用到其他画布」，选择已有目标或新建画布。仅复制选中的片段，保留原画布、原消息、UTF-16 选区和完整原文哈希；可跳回原文并高亮。原文不可用时仍保留引用快照。
- 备份与恢复仅作用于当前画布。MCP／桌面任务、确认、回溯卡片、图片和导出按所属画布隔离；模型登录、模型／深度、项目目录和整合设置共用。

本版应用幂等的数据库 migration 003，增加画布目录与本地任务归属记录。新画布使用独立 SQLite 文件，原数据库路径与原文身份保持不变。新增目录随应用数据一起保留。含跨画布来源的原生 JSON 备份需使用 0.7.0 或更新版本导入。

在「版本与更新」检查、安装并重启即可；不需要 GitHub token。浏览器里未发送的草稿和任一画布的生成任务会阻止安装。
