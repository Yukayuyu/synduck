# Context Canvas 0.8.0

- 输入框新增「交给本地任务」：带入草稿或最近提问及检查过的上下文，进入项目任务后再确认启动。普通对话会说明 Synduck 内的开发入口。
- AI 回答与本地任务回复支持 Markdown 阅读，包括标题、列表、表格和代码块。原文、哈希、历史输入包及 Pick 的 UTF-16 来源保持不变。
- 对话框可从右下角拖动调整宽高，也可从卡片菜单输入数值或恢复自动尺寸。尺寸随重启和备份保存。
- 输入「选项」改为浮层，展开时保持卡片和发送区大小，点外部或按 Escape 可关闭。

现有内容继续保留；本版没有 SQL migration。含新 `size_mode` 字段的原生备份需用 0.8.0 或更新版本导入。

在「版本与更新」检查、安装并重启即可。开发用法见安装包 `docs/developer-workflow.md`；安装与更新不需要 GitHub token。
