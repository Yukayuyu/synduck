# Context Canvas 0.5.5

三版可以直接切换的画布风格：Arc 弧面、Paper 纸感、Ink 墨色。右上角「⋯」→「画布外观」，点击即可预览，当前浏览器会记住选择。

- 对话采用更简洁的标题栏、大圆角和紧密问答分块；空白卡片减少说明文字与空白占位。
- 中间摘录节点更小，使用独立弧形轮廓、引文图标和底色；自动标题不再重复原文，自定义标题及来源记录保留。
- 输入区默认只显示传送与「选项」；预算和上下文预览收进选项。固定、排除、选择上下文等操作集中在卡片「⋯」及右键菜单。
- 节点以平滑曲线连接；手机上可通过点按菜单访问相同功能。
- 切换风格不重排节点、不重建输入框、不修改原文或封存上下文；多对话并行与独立停止继续可用。

此版本已纳入正式自动更新频道，不需要填写 GitHub token。在「版本與更新」检查、下载，保存草稿并完成任务后安装和重启。无需数据库迁移；画布、登录与模型设置会保留。
