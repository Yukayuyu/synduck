# Context Canvas 0.17.0

- 普通摘錄和匯合摘錄可保存自己的備註，先記下想法、稍後再延伸。保存不會呼叫 AI；原文與備註分開顯示，修改保留舊版本及既有回答的來源。
- 延伸提問或把摘錄加入上下文時，會帶上最新備註；仍遵循排除與預算，不會因超出預算而悄悄遺忘備註。
- 移除常駐的匯合／收集按鈕。選取文字後按右鍵「追加到摘錄…」，可搜尋目標；手機從選取工具列的「更多」進入同一選單。
- 恢復對話框四邊、四角自由拖曳調整；移除尺寸預設視窗，保留右鍵「恢復自動尺寸」。控制點位於卡片外側，觸控時加大，大小會跨重啟保留。

沒有 SQL migration；舊畫布與匯合點可繼續使用。含備註的備份需要 0.17.0 或更新版本匯入。Windows 與 Mac 沿用原本的安裝與更新方式。
