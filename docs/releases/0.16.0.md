# Context Canvas 0.16.0

- 送出问题后输入框立即清空，问题直接出现在对话中；发送失败时文字会放回输入框。
- 按 Enter 送出，Shift+Enter 换行。输入法选字时的 Enter 不会送出；触控键盘上 Enter 仍是换行，请点送出按钮。
- 新增 Claude 模式：在「模型與登入」贴上自己的 Claude API key 即可使用，可选择模型。key 只保存在后端，不回传浏览器。目前为纯文字回答，本地工具仍需 ChatGPT / Codex 模式。
- 新对话不再需要先命名：点「＋」或双击画布直接开始，标题自动取自第一个问题（可随时重新命名；自己起的名字不会被覆盖）。
- 设置改为「选」而不是「填」：
  - 本地项目用文件夹浏览器选择（含最近使用过的项目），选中即连接；手动输入路径收进折叠项。
  - MCP 本机程序的启动方式从常用清单选择，传入的后端变数与存取权杖从后端已有的 `MCP_` 变数中勾选（只列名称，不显示内容）。
  - 添加在线服务只需贴上地址，名称取自网址。
  - 对话框尺寸改为预设（紧凑／小／中／大／宽），其他尺寸仍可拖动角落调整。
  - 桌面卷动量改为方向与幅度的选项。
- 界面精简：底部工具栏、输入框按钮、卡片上的状态与入口都改为图标（悬停显示名称）；移除卡片的「主线／分支」文字标签、面板与对话框里的说明段落和装饰标题；「模型與登入」只显示所选模式的设置。与权限、安全和数据保管有关的提示保留。

「模型與登入」现在先选回答模式，再显示该模式的登录。无 SQL／画布迁移。详见 [Claude 模式](../claude.md)。
