# Context Canvas 0.12.0

- 新增 macOS 可攜式 ZIP，同時支援 Apple Silicon 和 Intel Mac（macOS 13.5 或更新）。完整解壓後雙擊 `Start-Synduck.command`；首次啟動自動下載並校驗原生 Node.js 24.19.0，準備固定版本依賴並開啟瀏覽器，不需 Homebrew 或預先安裝 Node。
- Mac 支援畫布、ChatGPT / Codex 登入、文件參考、本地檔案／終端及已配置的 MCP。桌面視窗擷取和輸入驅動仍限 Windows。
- Mac 使用獨立更新清單，沿用保留畫布／登入的安裝、回退及中斷恢復；Windows 更新來源和舊客戶端相容性保留。更新器拒絕混用不同平台的 ZIP。
- 加入 Apple Silicon／Intel macOS CI，檢查實際 ZIP 權限、首次啟動、簽出狀態 Codex、重啟資料保留及升級恢復。

Mac ZIP 是本地後端與瀏覽器啟動器，並非 Apple 簽署／公證的 `.app`。若系統攔截，依「隱私權與安全性」提示允許開啟，或在終端機以 bash 執行啟動檔。完整步驟見包內 `app/docs/macos.md`。

沒有 SQL 或畫布資料遷移。安裝與匿名更新不需要 GitHub token。
