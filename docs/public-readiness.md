完整 Git bundle 和分支名／SHA 对照表保存在工作区内、Git checkout 外的私有备份目录，不会随 `git push` 或 Windows 发布包上传。备份包含清理前内容，不应上传至公开下载仓库。可以用以下方式恢复某个旧分支：

