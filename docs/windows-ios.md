# Windows、iPhone／iPad 与 ChatGPT 登录

程序的后端、SQLite、模型连接和本地工具运行在电脑上。Windows 可以运行完整后端和目标窗口控制；iPhone／iPad 通过 Safari 连接同一个后端。后端电脑需要保持开机。

## 先在电脑启动

Windows 可使用完整安装 ZIP，也可以从 `main` 克隆源码运行，按[安装与配置指南](setup.md#启动程序)操作。源码运行需要 Node.js 24.19.0 和 pnpm 11.19.0；安装包会准备固定版本的运行环境。

先在电脑本机确认画布能打开，再配置手机访问。日常源码启动采用 `pnpm build` 后的 `pnpm start:local`，使用端口 `3001`；开发模式 `pnpm dev` 的前端在 `3000`。手机访问使用已构建的应用入口。

## ChatGPT 登录、模型与思考深度

1. 打开「模型與登入」→「使用 ChatGPT 帳號登入」。
2. 打开程序显示的官方授权链接，登录账号并输入设备码。可以在电脑或手机浏览器完成授权。
3. 等待显示已连接，选择「ChatGPT / Codex」。
4. 刷新「Codex 模型」清单，选择有效模型与「思考深度」，点「使用此模式」。
5. 提交一条简短问题，以实际完成的回答确认连接可用。

这使用官方 Codex App Server 的设备码授权，不需要自己注册 OAuth 应用，也不需要填写 OpenAI API key。需要账号具有相应 Codex 使用资格；组织策略、设备码登录设置、模型权限和额度由服务决定。代码过期时取消后重新登录。

模型和思考深度来自官方目录，没有写死某个模型版本。旧选择失效时需明确重新选择；不支持可调深度的模型只提供「模型預設」。切换模型后重新选择深度，较高深度通常需要更长时间。生成期间不能修改模型。

模式、模型和深度保存在 `data/model-settings.json`，优先于 `.env` 的初始值。Codex 登录保存在本应用的 `data/codex/`，不会替换你其他 Codex 安装的登录。所有连接到同一个后端的设备共享这个模型账号；登出模型不会删除画布。

直接 API 模式另用 `LLM_MODEL`／`LLM_API_KEY`，设置方法见[连接 AI](setup.md#连接-ai)。不需要同时配置两种接入方式。

## 在 iPhone／iPad 上打开

### 1. 准备可信 HTTPS 地址

选择一个手机能访问的 HTTPS 地址，指向后端电脑。可以使用自己管理的反向代理或私人网络的 HTTPS 入口。配置网络、DNS 和 TLS 的服务由你管理，程序不会自动创建这些资源。

### 2. 设置后端 `.env`

安装包使用与 `Start-ContextCanvas.cmd` 同级的 `.env`；源码使用仓库根目录的 `.env`：

```dotenv
API_HOST=127.0.0.1
API_PORT=3001
PUBLIC_ORIGIN=https://canvas.your-domain.example
APP_PASSWORD=<在自己的后端填写至少16字符的独立密码>
```

把示例地址换成实际地址。`PUBLIC_ORIGIN` 必须是完整 HTTPS origin，与手机访问地址完全相同，**不带路径或末尾斜线**。工作区密码与 ChatGPT 密码、API key 分开。

若反向代理与后端在同一台电脑，保留 `API_HOST=127.0.0.1`。代理位于另一台机器时才根据网络情况调整监听地址；非本机监听仍要求 `PUBLIC_ORIGIN` 和工作区密码。

### 3. 配置反向代理并重新启动

同机 Caddy 示例：

```caddyfile
canvas.your-domain.example {
    reverse_proxy 127.0.0.1:3001
}
```

替换为实际域名，并完成 DNS、可信证书和必要的网络连接配置。其他代理同样需要保留请求 Host、转发 `/api/`，并支持流式回答而不等到整段完成后才返回。

修改后重新启动整个 Windows 启动器。源码安装如果尚未构建，先执行 `pnpm build`，再 `pnpm start:local`。单纯修改后端密码或 origin 不要求重新构建前端。 启用 `PUBLIC_ORIGIN` 后，电脑和手机都应从配置的 HTTPS 地址进入，以符合后端的 Origin 校验。

### 4. 在 Safari 登录工作区

1. 手机连接到可访问该地址的网络，打开配置的 HTTPS 地址。
2. 输入 `APP_PASSWORD` 对应的工作区密码。
3. 使用浮动工具栏打开提问、对话或上下文面板；这些设备访问的是同一份后端数据。
4. 可用 Safari「分享」→「加入主画面」创建入口。

工作区会话有效期为 12 小时，后端重启后需重新登录。手机上的 localhost 指向手机自己，不能替代电脑的 HTTPS 入口。程序不是 iOS 原生／离线应用；后台不运行时，手机无法继续使用模型或本地工具。

## 已登录但回答失败

| 显示或现象                                | 含义与处理                                                                       |
| ----------------------------------------- | -------------------------------------------------------------------------------- |
| `/api/session` 返回 `authenticated: true` | 工作区访问已通过，不表示 ChatGPT、模型或额度已验证                               |
| ChatGPT 显示已连接                        | 可以读取官方账号状态；仍需一次成功生成确认模型可用                               |
| 几秒内失败                                | 查看具体诊断，优先检查模型、授权、额度／速率或请求被拒；这不是三分钟生成期限到达 |
| 模型不在清单或深度已失效                  | 刷新目录，重新选择模型／深度并保存                                               |
| 长时间中断或超时                          | 根据诊断检查网络／服务状态；保留原始问题和工作区，不要清空数据重装               |

诊断入口为「模型與登入」中的最近一次 Codex 回答失败信息；后端还提供 `/api/models/codex/diagnostics`。诊断显示错误码、阶段和耗时，不包含凭证、邮箱、对话正文或原始服务错误。它只保存在当前进程内，重启后需要再次复现才能查看。

普通画布回答使用检查器编译的文本上下文；本地任务通过单独入口使用已启用的项目工具、MCP 或桌面操作。模型登录不会自动批准任何本地命令或外部工具调用。

## 桌面操作与数据

手机可以查看和确认后端 Windows 的窗口操作，不能因此控制 iPhone 其他 App。先在「本地任務 → 整合設定」选择后端窗口，具体设置见 [MCP 与桌面控制](mcp-desktop-traces.md)。窗口授权在重启后失效，需要重新选择。

画布、模型设置、登录和操作记录均在后端 `data/`。升级前停止后端，备份 `.env` 和完整 `data/`，按[升级步骤](local-runtime-updates.md)保留原工作区。

## 验证范围

Windows／Linux CI 已覆盖核心测试、安装与升级／回退、旧启动入口兼容性和未登录 Codex 初始化；Windows 还验证原生窗口枚举与编译包内的桌面桥接。Linux CI 的 Chromium 与 WebKit 手机布局测试已通过。

这些检查不替代实体 Windows 截图／输入、真实账号的模型生成、实体 iOS 的键盘、原生文字选择与主画面安装体验。网络访问需要对应服务可达：Codex 使用 `auth.openai.com`／`chatgpt.com`，API 模式使用 `api.openai.com`；保留 TLS 验证。Playwright 浏览器安装另需官方 CDN 和主机系统依赖。
