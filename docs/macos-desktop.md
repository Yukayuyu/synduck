# macOS 桌面控制（實驗性）

Mac 後端可以擷取選定的應用程式視窗，並在其中點擊、雙擊、輸入文字、按快捷鍵與捲動。操作流程、逐次確認和前後截圖紀錄與 [Windows 桌面控制](mcp-desktop-traces.md#windows-桌面控制)相同。

**狀態：實驗性。** 每次 CI 都在 GitHub 的 Apple Silicon 與 Intel macOS 15 執行環境，對真實的 TextEdit 視窗檢查列舉、擷取、點擊、貼上輸入、Command 快捷鍵與捲動，並以剪貼簿內容確認文字確實進入視窗。尚未在實體 Mac 上由真人驗證，其他應用程式、多螢幕與不同系統版本的表現未知。請先在不重要的視窗試用。

## 需要的系統權限

macOS 把權限授予**啟動 Synduck 的程式**，通常是「終端機」（雙擊 `Start-Synduck.command` 時就是它）。在「系統設定 → 隱私權與安全性」：

| 權限           | 用途                       | 沒有時的表現                       |
| -------------- | -------------------------- | ---------------------------------- |
| 螢幕與系統錄音 | 擷取視窗、顯示完整視窗標題 | 擷取失敗；視窗清單只顯示應用程式名 |
| 輔助使用       | 點擊、輸入、快捷鍵、捲動   | 操作被拒絕並提示授權               |

授權後需要結束並重新啟動 Synduck。Synduck 不會自行要求或修改這些權限。

## 使用

1. 開啟目標應用程式，讓視窗留在畫面上（不要最小化）。
2. 「本地任務 → 整合設定 → 桌面控制」刷新視窗、選擇目標並啟用。
3. 先擷取一次，再依截圖中的座標提出操作。每次觀察與操作都要確認。

## 與 Windows 的差異

- **快捷鍵：** 清單中的 `Control+A／C／V／Z／S` 在 Mac 上送出 `Command+A／C／V／Z／S`。
- **文字輸入經由剪貼簿貼上**，以完整支援中文等 Unicode 文字。貼上後約一秒放回原本的純文字剪貼簿內容（等目標程式讀完剪貼簿，避免在較慢的 Mac 上貼成舊內容）；圖片、檔案等非文字內容無法還原，輸入期間剪貼簿管理工具可能記錄到該段文字。
- **目標是應用程式的視窗，前置以應用程式為單位。** 操作前會啟用目標應用程式，並確認目標視窗是最前面的一般視窗且大小位置未變；若同一應用程式的另一個視窗在前面，操作會停止並請你手動點一下目標視窗。
- 擷取使用系統的 `screencapture` 並縮放到最長邊 1280 像素；Retina 螢幕的座標換算已處理。
- 不支援拖曳、全螢幕空間／其他桌面空間中的視窗、最小化的視窗、登入視窗與鎖定畫面。

重啟後必須重新選擇視窗。操作目標是執行後端的那台 Mac，不是瀏覽器所在的裝置。
