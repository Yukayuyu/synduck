# 摘錄備註、右鍵追加與自由調整（0.17.0）

摘錄可以先存下來、寫備註，等想清楚再延伸，不必立刻向 AI 提問。

## 在摘錄裡記下想法

1. 打開普通摘錄或匯合摘錄，點「備註」；也可以在卡片上按右鍵選「編輯摘錄備註」。
2. 寫下想法，點「保存備註」。Enter 正常換行，Ctrl／Command+Enter 也可保存，輸入法選字不會觸發保存。
3. 備註顯示在原文下方的獨立區塊。保存或修改不會呼叫 AI；切到其他對話後仍可看到備註。
4. 之後按「延伸提問」，會把摘錄、匯合來源及最新備註一起作為背景。亦可將整張摘錄加入其他對話的上下文。

備註可修改或清空，舊文字與以前的回答來源都會保留。原文、選取位置與原文雜湊不會因此改動。尚未點保存的文字留在編輯框，關閉視窗會放棄此次編輯。若其他視窗先更新同一份備註，程式會提醒衝突並保留當前編輯框的文字，不會覆蓋他人的修改。

備註上限為 20,000 字元。與摘錄一起供應給 AI 時，仍遵循固定、排除、生命週期與上下文預算；排除整張摘錄或匯合點也會排除其備註。需要的內容超出預算時會阻止發送，不會悄悄省略你的備註。這只影響之後編譯的輸入，已封存的舊回答不會改寫。

## 透過右鍵追加來源

選取對話、筆記或參考文件裡的文字，按右鍵選「追加到摘錄…」，再選目標。可輸入關鍵字尋找既有摘錄，追加後會定位到更新的卡片。手機可用選取工具列的「更多選取操作」開啟同一選單。選取工具列及卡片內不再常駐匯合按鈕。

追加的是選取的原文片段，保留原本的來源與範圍。其他卡片的未選內容不會跟著加入。原本已建立的匯合點繼續可用。

## 直接拖曳大小

點選對話卡片後，拖曳四邊或四角即可。邊緣可單獨調寬或調高，角落同時調整；在不同畫布縮放比例下都按實際拖曳距離計算。控制點放在圓角卡片外側，觸控時加大，避免被遮住或誤拖整個畫布。

尺寸會保存，重新開啟、折疊再展開或匯入備份仍保留。最小 340×360，最大 1600×1800；右鍵選「恢復自動尺寸」可回到自動版面。已移除尺寸預設選項。

此版沒有 SQL migration。含備註的畫布備份需要 0.17.0 或更新版本匯入；完整備份包含備註的所有版本。
