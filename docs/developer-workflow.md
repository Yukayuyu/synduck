# 在 Synduck 中开发项目（0.9.0）

普通画布对话现在直接支持项目工具。无需再点「交给本地任务」或把问题复制到另一个输入框：模型按请求自行决定是否读取文件、提出修改、执行命令或调用已配置的 MCP／Windows 桌面工具。最终回答与操作记录留在原来的对话卡片中。

## 首次设置与日常使用

1. 在「模型与登录」完成 ChatGPT 登录，选择有效的 Codex 模型与思考深度。Demo 和直接 API 模式仍提供文字回答，不执行本地工具。
2. 打开顶部终端图标「本地任务」，填入**后端电脑**上已有的项目目录，启用并保存。尚未克隆源码时，可以先选已有的父目录，再在画布要求克隆和安装依赖。后端需安装 Git、Node.js 24 和 pnpm，并能访问所需网络。
3. 回到普通画布输入框，直接提出需求，例如“读取项目的 AGENTS.md 和 package.json，检查测试命令并修复这个错误”。不需要选择模式或另行启动任务。已启用项目的安装升级后也使用这一流程；如需停用，取消项目设置中的启用勾选。
4. 列目录和读取文件自动执行。写入、命令、MCP 探索／调用和桌面操作会在同一回答的「工具」区域显示具体参数，确认后执行；拒绝后将真实拒绝结果交还模型。MCP 与桌面需要预先配置和启用。
5. 结束后可展开「工具」回看每一步的参数、实际结果、Action ID 与截图，或导出记录。记录与该回答的输入包关联，后端重启后仍可查看；不会伪装为画布引用来源，也不会修改已封存的上下文。

模型拥有工具能力不代表每次都会调用；纯文字问题不占用执行器。多段普通对话可以同时生成；同一时间仅允许一段对话使用共享项目执行器，另一个对话如需工具会收到“已有任务”的真实结果，不会在后台排队后意外执行。可等前一段结束后发新问题继续。

「停止这段回答」、关闭回答连接或从旧任务面板停止，都会停止该轮后续操作并撤销待确认请求。已经完成的写入与外部副作用不会自动回滚。包含写入／命令／外部工具记录的失败回答禁止直接重试；先查看结果，再发新问题，避免把已执行的动作重复一遍。重启后中断的任务不会自动重放。

顶部面板保留项目设置、整合设置、手动测试和旧任务记录；普通开发不再需要其中的独立 AI 任务输入框。详见[安装指南](setup.md)与[执行器限制](local-runtime-updates.md)。

## 开发 Synduck 自身

推荐使用安装好的稳定版界面，操作单独克隆的 `Yukayuyu/synduck` Git 源码目录。Windows ZIP 中主要是编译产物，开发需要完整源码。调试新版使用另一组端口，稳定版继续保留画布和本地任务连接。源码安装的开发服务器由你启动、停止；任务中避免重启承载当前任务的后端。

每个开发任务需要明确需求、验收条件和项目约束。模型已被要求先读取项目指令；仍应核对实际操作记录。先检查分支、版本和 `git status`，读取 `AGENTS.md`、`package.json` 与相关源码；重要规则直接写入任务或显式附加到画布上下文。仓库文档与本次聊天历史不会自动加载。这个项目默认在 `main` 工作，保留原文、出处和已封存输入包；不擅自引入多智能体或图数据库。结束时报告改动、检查结果及未完成事项。

一次只执行一个使用工具的本地任务，每轮最多 20 个操作、15 分钟（包括等待确认）；命令默认 60 秒、最多 120 秒。读文件最多向模型返回 20 KB，超过 64 KB 的文件不能用内置整文件读写工具处理。工具向模型累计回传的文本最多 100 KB，图片最多 8 张／16 MiB；达到上限会明确返回限制。画布上下文预算只衡量编译的画布输入，工具定义、执行环境和本轮工具证据会额外消耗 token，后续提问不会自动带入整份工具记录。较大的文件和检查需要按范围定位、通过确认后的命令处理，或分成多个任务。不要用截断的文件片段覆盖完整文件。MCP 与桌面工具仍遵循原有逐次确认和记录规则。原生 Codex 的 skills、内置浏览器、自动长任务续接和全部工具并未因此全部接入；本版统一的是画布对话与现有执行器的入口。

ChatGPT 登录授权模型，不等于 GitHub 推送授权。提交、推送和发布需要后端电脑自己的 Git 配置及凭证；安装与匿名更新仍不需要 GitHub token。

## Markdown 阅读与 Pick

AI 回答、生成中的文字、本地任务回复和追溯页支持标题、粗体、斜体、列表、任务列表、引用、链接、表格与代码块。用户输入和工具原始输出保持原文显示。HTML 作为文字显示，图片显示为可打开的链接。

格式化只改变阅读层。原始 Markdown、内容哈希与历史输入包保持不变。Pick 按原始 UTF-16 范围保存；选择跨越多种格式时，范围内的 Markdown 标记也会保留在摘录快照中。来源高亮与连接线使用同一组映射，不会把排版后的字符数量误当原文位置。卡片菜单的复制仍取得原文。

## 对话框大小与输入选项

打开对话后，拖动右下角手柄调整宽高。也可在卡片「⋯」或右键菜单选择「调整对话框尺寸」，输入数值，或恢复自动尺寸。手动宽度范围 340–1600，高度 360–1800；尺寸随画布保存、重启和单张备份保留，折叠不清除设置。

「选项」使用浮层，展开时不改变卡片大小或挤走发送按钮。点其他区域、再次点选项，或在菜单内按 Escape 可关闭；只有明确的键盘关闭会把焦点返回选项按钮。

本版新增可选节点字段 `size_mode`，复用现有宽高字段，无 SQL migration。旧画布继续自动排版；含该字段的 JSON 备份需要 0.8.0 或更新版本导入。
