# 0.5.0：讓問答連在一起的分塊閱讀

對話卡現在按每次輸入分組：上方淡色的「輸入」塊與下方白色的「輸出」塊對齊，中間只留一條細縫和短接線。下一組問答留出稍大的空白，並以 01、02 等序號標記。沒有左右交錯的氣泡或頭像；長回答的段落留在同一個輸出內，共用對話卡的捲動區。

輸出生成中會和已提交的問題一起顯示，標示「生成中 · 尚未保存」。送出長問題後會捲到新輸出；若閱讀者往上捲回舊內容，後續生成不會持續把視線拉回底部。讀取保存結果時保留目前區塊，直到已保存回答就緒。重試沿用原問題所在的組別；只有完整驗證後的回答才成為可摘錄的原文。輸入框繼續使用原生 textarea，打字和回答更新時保留同一個元素。關閉「接續輸入」右側的 ×，可收起輸入框並增加閱讀空間；點「繼續提問」再打開。

## 辨識摘錄與分支

| 區域     | 外觀與操作                                                                     |
| -------- | ------------------------------------------------------------------------------ |
| 對話     | 淡色輸入＋白色輸出，緊密成組；輸出下方可查看該輪歷史上下文                     |
| 摘錄     | 暖色紙張、引文側線及較方的左角；「回到原文」定位並高亮來源，「延伸提問」開分支 |
| 分支     | 保持對話分塊，上方增加暖色來源標記；點標記回到摘錄原文                         |
| 來源連線 | 暖色虛線表示摘錄原文，紫色實線表示延伸提問；連線上有文字標籤                   |

拖曳標題移動整張卡片，拖曳內容選取文字。跨空行的文字仍可一次摘錄；原文 block、UTF-16 範圍、快照及 SHA-256 都保留。畫布分組只改顯示，沒有拆分、重寫或遷移儲存的訊息。回到來源的捲動也會配合畫布縮放定位。

## 更新本地版本

已使用管理式 Windows 啟動器：先保存未送出的文字並完成任務，在「版本與更新」匯入完整 `ContextCanvas-Windows-0.5.0.zip`，再安裝及重啟。刷新頁面後確認版本為 **0.5.0**。更新保留畫布、來源記錄、登入及模型設定；沒有新增資料庫 migration。

首次安裝請完整解壓 ZIP 並執行 `Start-ContextCanvas.cmd`。更早的非管理式安裝，請參閱[首次升級說明](local-runtime-updates.md#windows-使用與首次升級)。原始碼安裝需重新構建前端並重啟本地啟動器。

此 ZIP 供本地匯入，未發布 GitHub Release，因此線上檢查不會發現它。瀏覽器測試使用本地 Demo；Chromium 的觸控與組合輸入模擬不代表 Windows 中文輸入法或 iOS Safari 的實機驗證。
