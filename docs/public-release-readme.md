# Context Canvas

在大画布上阅读对话、摘取文字并延伸分支，查看 AI 使用的上下文，以及回看本地工具和窗口操作。

> 这是首次公开发布时使用的说明模板。目前尚无正式 Release；维护者需在发布完成后核对下载地址，再将本文件用于公开下载页。当前状态与发布配置见 [GitHub 发布说明](github-updates.md)。

## 下载与启动

1. 正式发布后，在本产品的 GitHub Releases 下载 `ContextCanvas-Windows-<版本>.zip` 附件；不要选择自动生成的 Source code ZIP。
2. 完整解压缩，再双击 `Start-ContextCanvas.cmd`。支持 Windows x64／ARM64，首次启动需要连网准备运行环境和固定版本依赖。
3. 保持启动器窗口开启，在自动打开的浏览器使用画布。可以先用不调用真实模型的 Demo 模式体验。
4. 使用真实模型时，在「模型與登入」登录自己的 ChatGPT 账号，选择 ChatGPT / Codex、模型和思考深度，再点「使用此模式」。也可按安装包内说明配置直接 API 模式。

安装和匿名更新不需要 GitHub 账号或 token。程序内「版本與更新」可检查、下载和选择安装时间；升级保留画布、登录和任务记录。详细设置在安装包的 `app/docs/setup.md`。

## 已有安装

取得更高版本的完整 ZIP，在原程序匯入并安装，完成后关闭并重新启动整个启动器。更早的安装可按说明使用新包的 `Update-Existing.cmd`。先备份重要数据，保留原安装的 `.env` 与 `data/`。

## 运行与许可

程序在后端电脑运行。iPhone／iPad 需通过可信 HTTPS 连接该后端；MCP 和桌面控制按具体服务登录及操作确认提供权限。没有关闭后端后的离线使用能力。

项目采用 MIT 许可证，许可正文随安装包提供；第三方依赖和资产保留各自许可证。分发包含编译后的程序和可查看的运行资源。
