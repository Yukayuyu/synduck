# 0.4.0：更直接的畫布操作

本次把 block 按畫布上的整張對話／摘錄卡片處理。原本這兩類卡片沒有刪除入口，只有本地操作紀錄能移除；現在加入右鍵選單、手機可用的「⋯」、可復原的刪除和回收桶。對話內單則訊息／ContentBlock 的永久刪除不在這次功能中。

## 常用操作

| 想做的事                 | 操作                                                         |
| ------------------------ | ------------------------------------------------------------ |
| 在指定位置開始提問       | 空白處右鍵 →「在這裡提問」，直接開始輸入                     |
| 傳送問題                 | 輸入後點「傳送」；需要先檢查時，仍可選「预览上下文」         |
| 改卡片名稱               | 卡片右鍵或「⋯」→「重新命名」，輸入後按 Enter                 |
| 複製卡片文字             | 卡片右鍵或「⋯」→「複製內容」                                 |
| 選取、固定或排除上下文   | 在卡片選單中直接切換                                         |
| 從摘錄開新分支、追溯來源 | 摘錄選單 →「從摘錄延伸提問」或「回到來源」                   |
| 整張畫布總覽             | 空白處右鍵 →「顯示全部卡片」；可再從「對話」列表回到單張卡片 |
| 刪除卡片                 | 卡片選單 →「刪除卡片」，下方可立即「復原」                   |
| 找回已刪除卡片           | 下方回收桶或空白處右鍵 →「回收桶」，搜尋、檢視、還原         |

選中一張畫布卡片並讓畫布取得焦點後，也可用 Delete／Backspace 刪除、F2 重新命名。文字輸入區保留原本的 Backspace、選取、撤銷及右鍵複製／貼上。選單支援上下方向鍵、Home／End、Enter 和 Escape。

直接傳送仍會先編譯並驗證實際上下文；超過預算或來源有問題時不會呼叫模型，草稿會保留並打開原因說明。回答中的歷史上下文包仍可檢視。

## 刪除與來源

一般刪除是一個動作，只有未送出的草稿需要確認。最近一次刪除的草稿可由「復原」提示找回；關閉提示、刪除下一張或關閉頁面後，草稿不會保存在回收桶中。請先複製需要保留的未送出文字。

刪除會把卡片收進回收桶，隱藏相關畫布連線，不會清空磁碟上的原文、分支或歷史輸入快照。這次沒有永久清除資料的功能。新上下文和舊失敗回答的重試都會排除已刪除來源、同來源別名及依賴它的衍生回答。刪除一張摘錄可能排除其整個來源文字塊，沿用現有排除政策。

分支仍可「回到來源」：來源卡片已刪除時，會在回收桶唯讀顯示並標示原文範圍，不會自動還原或重新加入 AI 上下文。還原保留原卡片 ID、來源關係與固定／排除設定；原位置被新卡片占用時，只把還原卡片移到附近空位。回答生成中會暫停刪除、還原與重新命名。

## 相容性與更新

使用既有 `Node.visibility=hidden` 記錄回收桶，不新增 SQLite 資料表；原生 JSON 備份包含回收桶和完整來源。縮放驗證範圍從 0.1–4 擴大為 **0.01–4**，畫布也允許 1% 總覽。舊版本無法直接讀取低於 0.1 的新工作區縮放設定；如需使用舊版，先在 0.4.0 把縮放恢復到至少 10%。舊版也不會隱藏回收桶卡片。啟動器的失敗回退繼續還原升級前的資料快照。

已使用 0.2.x／0.3.x 啟動器：先保存並清空未送出的文字，完成任務後，在「版本與更新」匯入完整 `ContextCanvas-Windows-0.4.0.zip`，安裝重啟並刷新頁面。確認版本顯示 **0.4.0**。此包供本地匯入，未發布 GitHub Release，線上檢查不會發現本地檔案。

瀏覽器與觸控模擬可驗證操作路徑；Windows 實體桌面、iOS 原生鍵盤及真實模型回答仍需各自實機驗證。
