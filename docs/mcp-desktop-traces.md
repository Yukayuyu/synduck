# MCP、桌面控制與畫布操作紀錄

目前版本支援 MCP stdio／Streamable HTTP 工具，以及 Windows 上選定視窗的擷取、點擊、雙擊、文字輸入、快捷鍵與捲動。桌面截圖會交回本地任務使用的 Codex 模型，接續觀察與操作；一般畫布回答仍維持原本的文字上下文流程。

## 安裝與首次測試

先按[安裝與配置指南](setup.md)啟動目前版本。已有安裝的更新與資料保留方式見[本地執行器與版本更新](local-runtime-updates.md)；首次取得 Windows 包後，完整解壓縮並執行 `Start-ContextCanvas.cmd`。

開啟「本地任務」，保存並啟用後端電腦的專案目錄，再進入「整合設定」。MCP、桌面操作和專案工具使用同一個任務紀錄與逐次確認流程；任務開始後自動在 canvas 顯示一張操作卡片。

## MCP 設定

「新增 MCP」可設定服務名稱、連接方式與啟用狀態。保存設定後，按「提出連接與探索工具」並確認，才會啟動服務與讀取目錄。

- **stdio**：填入可執行程式，例如 node／npx，以及 JSON 字串陣列格式的參數。工作目錄為已選專案，啟動程式以後端 OS 帳戶權限執行。
- **Streamable HTTP**：填入 HTTPS MCP endpoint；本機 loopback 可用 HTTP。網址不可嵌入密鑰，需要 Bearer token 時指定後端環境變數名稱。
- **密鑰**：只在後端根目錄 .env 設定，以 MCP\_ 開頭，例如 MCP_SERVICE_TOKEN。介面只保存名稱；stdio 只轉交明確列出的 MCP 變數及基本系統環境，HTTP 不跟隨授權重新導向。
- 這版支援無驗證或後端 Bearer 授權的遠端服務；MCP OAuth 授權頁尚未接入。ChatGPT 登入負責模型授權，不能替代外部 MCP 的登入。

「新增瀏覽器 MCP 預設」會填入 Playwright MCP 0.0.83（npm 已存在的固定版本），使用本機 Chrome。需要已安裝 Chrome、可連到 npm，首次下載可能較久。這是設定預設，不代表第三方服務已通過實機驗證，也不會在新增時自動執行。

工具探索完成後，「手動測試 → MCP」可選服务與工具、查看 inputSchema、填入 JSON 參數並提出呼叫。後端先驗證參數，每次呼叫都需確認，包含標示唯讀的工具。工具描述與回傳內容視為外部資料，不會改寫模型的固定操作政策。

AI 任務可使用 canvas_mcp_tools 與 canvas_mcp_call。服務、工具描述／schema、實際參數、結果、錯誤與圖片留在該 action 紀錄。外部服務中斷或取消可能已有副作用，程式不自動重試工具操作。

## Windows 桌面控制

1. 開啟要操作的應用程式。
2. 在「整合設定 → 桌面控制」刷新視窗、選擇目標並勾選啟用，保存設定。
3. 在「手動測試 → 桌面」提出擷取並確認，取得第一張畫面。
4. 點圖片選擇座標，或選文字／快捷鍵／捲動，再提出下一步；確認後才實際操作。
5. AI 任務也能先擷取畫面，再依圖片提出操作。從本地任務或畫布操作卡片開啟回看與確認；「停止任務」停止後續生成與本機操作。

所有觀察與操作都需確認，包含會切換視窗的擷取。操作目標是**後端 Windows 的應用視窗**；iPhone 頁面作為控制與回看介面，不會因此取得手機其他 App 的控制權。無 Windows 互動式桌面的雲端／Linux 後端會顯示不支援原因，不生成假截圖。

畫面最長邊縮放至 1280 像素。capture_id 是該次觀察的 UUID，PNG 的 SHA-256 用於圖片完整性。點擊座標以該張圖片的像素為準，後端按保存的視窗區域轉換為實際螢幕座標。

操作只接受本任務內、五分鐘內的截圖。每步確認後重新擷取操作前畫面，檢查目標程序、視窗位置與大小；變更則保留新畫面並停止該操作，需要重新提出。點擊點被其他視窗遮擋或 Windows 阻止焦點／輸入時也停止。畫面內容可能動態變化；幾何檢查不能保證應用內按鈕語義不變。

重啟／升級後必須重新選擇並啟用視窗，避免舊 handle 被重用。這版不支援全桌面自由搜尋、拖曳、UAC 安全桌面、鎖定螢幕或高權限視窗的繞過。快捷鍵從限定列表選擇，Unicode 輸入不改寫系統剪貼簿。

## 回看與追溯

畫布卡片顯示最後畫面、最近步驟、任務狀態與待確認提示；可拖動，位置在重啟後保留。任務附有畫布上下文時，用來源包的 current_node_id 產生確定的「輸入上下文」連線，不把視覺卡片偷偷當作模型上下文。

「回看與追溯」可逐步選擇、對照操作前後圖片，查看點擊位置、輸入文字／快捷鍵、確認時間、完成時間、Task／Action／Capture ID、目標窗口、模型與深度、版本、工具結果及圖片 SHA-256。參數與原始結果折疊顯示，避免佔滿畫布。

「輸入已送出」只表示 OS 輸入呼叫完成；應用內是否保存或成功，仍要看操作後畫面與後續工具證據。操作開始後中斷時，紀錄標明結果未確認，不宣稱沒有副作用。重新啟動不自動重播操作。

模型每個任務最多接收八張圖片、合計 16 MiB；文字工具結果另受原有 100 KB 預算限制。紀錄保存實際送回模型的文字與圖片 hash，圖片省略會明示；模型政策要求缺少必要圖片時停止。每個任務仍最多 20 個操作，紀錄圖片預算約 64 MiB。

「匯出紀錄與圖片」產生 ZIP，含 task JSON、引用圖片與 hash manifest；目前畫布仍有該輸入包時，也包含完整 Context Package。這是操作紀錄匯出，不能當作原生畫布 JSON 匯入，也不會自動匯入／重播操作。

紀錄、MCP 設定、桌面偏好、圖片與卡片位置都保存在 `data/local-runtime/`。完整 data 備份／版本回退保留它們；原生畫布 JSON 仍不包含這個獨立目錄。移除卡片只改版面，紀錄不刪除；已固定的舊任務可超出最近 50 筆列表繼續回看。圖片 API 與匯出沿用工作區登入、Origin／Host 保護。

## 驗證範圍

已使用官方 MCP SDK 實際啟動本機 stdio 與 HTTP fixture，驗證探索、參數、確認／拒絕、錯誤及圖片。模型動態工具迴圈、圖片上限與 Windows 驅動操作使用受控測試；真實 ChatGPT 多模態工具任務和實體 Windows 操作仍待驗證。

Chromium 測試使用明確標示「模擬桌面」的測試視窗，驗證 UI 確認、前後對照、點擊標記、拖動、重載與匯出。Windows 專用檢查會在該平台編譯 PowerShell／C# 並列出視窗；Linux 不執行這個檢查。它不替代 Windows 輸入／擷取的實機測試。
