# 文件與文字參考（0.10.1）

在畫布空白處按右鍵，選「在這裡匯入參考」，即可在該位置匯入文件或貼上文字。位置會依右鍵當下的畫布縮放與平移換算；若與現有卡片重疊，新參考會往下避讓到附近空位，不移動其他卡片。也可點底部「參考」使用預設放置位置。支援 UTF-8 TXT、Markdown（`.md`／`.markdown`）、可擷取文字的 PDF，以及 Word `.docx`。每次匯入建立一張獨立參考卡片，不會自動送給 AI，也不會建立假的使用者提問或模型回答。

## 加入對話

- 在參考卡片點「加入本輪上下文」，再回到要提問的對話傳送。也可從卡片選單選取、固定或排除，與其他節點相同。
- 點「以此提問」會建立一段新對話，並為本輪選取該參考。之後若要每輪帶入全文，可固定參考；只需一小部分時，Pick 文字建立摘錄或沿摘錄分支。
- 上下文檢查器可查看實際包含的原文及來源。選取或固定的全文超過預算時會阻擋傳送並說明原因，不會偷偷截斷。匯入上限不等於模型可以一次接收的上下文大小。

## 閱讀、搜尋與來源

小份 Markdown 支援排版。超過 40,000 UTF-16 字元的文件以每頁約 20,000 字元的原文分頁顯示，提供全文文字尋找；分頁只影響閱讀層。Pick、回到來源和連接線始終使用完整原文的 UTF-16 座標與 SHA-256，不把頁內位置誤當文件位置。選取內容也能加入匯合摘錄或引用到其他畫布。

文件保存的是匯入時擷取出的文字、原始檔名／格式／大小、原始檔案 SHA-256 及文字 SHA-256。PDF／Word 的原始二進位檔、圖片與版面未封存，也不提供原檔還原；請保留自己的原始文件。PDF 的欄位、表格及閱讀順序可能因原始版面而不同，使用前請核對。掃描 PDF、舊 `.doc`、圖片、網頁及其他格式請先轉為可讀文字；本版沒有 OCR、遠端網址抓取或 AI 自動摘要。

原文唯讀；要更新文件，匯入新的參考版本即可。既有摘錄和歷史輸入包繼續指向原版本，不隨電腦上的原檔變更。刪除參考會將它移到回收桶，原文可回看和還原，並從新的上下文排除；已生成回答的歷史輸入仍保留。

## 限制與保存

單檔最多 5 MiB；擷取或貼上的文字最多 1 MiB（以 UTF-8 位元組計算）。PDF 最多 250 頁；DOCX 展開後最多 20 MiB／2,000 個項目。PDF／Word 在獨立 worker 中解析，限制為 30 秒並設置 128 MiB JavaScript heap 上限；同時解析一份文件，其他文件可稍後重試。無法解析、密碼保護或無可讀文字時會顯示錯誤，且不建立半成品卡片。

參考及其來源資訊保存在所屬畫布的 SQLite，隨重啟、該畫布 JSON 備份／還原及程式更新保留；既有原生備份大小上限仍是 12 MiB。不同畫布的參考不會自動混用，須明確選取片段跨畫布引用。

本版復用既有 tool Turn、文字 ContentBlock 與 turn Node，沒有新增 SQL migration；匯入資訊記錄在 structured_data.reference。舊畫布正常使用，但舊版沒有文件卡片的閱讀介面，應使用 0.10.0 或更新版本處理含參考的畫布。
